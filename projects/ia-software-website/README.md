# IA Software Project Website

Static website

## Objective

Present IA Software projects through technical case studies and visual demonstrations.

## Implementation

The website organizes projects by topic, includes multilingual content, and incorporates interactive 3D scenes built with Three.js. It can be served as static files.

## Technologies

HTML, CSS, JavaScript, Three.js.

## Run the demo

From the portfolio root, run `python3 -m http.server 8000 --bind 127.0.0.1`. Open [the demo](http://localhost:8000/projects/ia-software-website/demo/).

Select an area to filter the illustrative catalog. See the [site structure](docs/site-structure.md).
